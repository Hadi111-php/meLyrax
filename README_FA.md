# 🌧️⚡ بستهٔ «باران» و «صاعقه» — LyraX Clip Studio

دو افکت **کاملاً مستقل و ماژولار** که هر دو هم در پیش‌نمایش مرورگر و هم در رندر سروری
FFmpeg کار می‌کنند. حرکات هر دو **قطعی (seeded)** هستند: پیش‌نمایش = خروجی نهایی.

---

## ۱) چه چیزی داخل بسته است؟

```
lyrax-weather-pack/
├─ install.sh                              ← نصب خودکار روی مخزن
├─ studio/
│  ├─ lyrax-studio-pro-v4-weather.html     ← داشبورد کامل (تک‌فایلی، آمادهٔ اجرا)
│  └─ js/modules/
│     ├─ lyrax-storm.js                    ← ⚡ صاعقه + 🌧️ بارندگی (کلید L و تیک «باران پیوسته»)
│     ├─ lyrax-weather.js                  ← موتور قبلی (رعدوبرق هماهنگ با ضرب)
│     └─ lyrax-fx.js                       ← نسخهٔ ۱.۲ (صاعقه/باران از lyrax-storm.js)
└─ backend/
   └─ renderers.py                         ← رندرر FFmpeg با لایهٔ باران و صاعقهٔ تایم‌لاین
```

---

## ۲) نصب

```bash
cd 3-LYRAX-CLIP-STUDIO          # ریشهٔ پروژه (همان‌جایی که app.py هست)
bash /path/to/install.sh
```

اسکریپت خودش نسخهٔ پشتیبان می‌گیرد (پسوند `.bak.باران-و-صاعقه`) و این کارها را می‌کند:

1. `backend/renderers.py` را جای‌گذاری می‌کند.
2. `js/modules/lyrax-weather.js` و `js/modules/lyrax-fx.js` را می‌ریزد.
3. داشبورد `lyrax-studio-pro-v4-weather.html` را کنار داشبورد فعلی می‌گذارد
   (فایل قبلی را پاک نمی‌کند).
4. در `backend/models.py` سه کلید `rain_overlay`، `weather_lightning` و `layer_fx` را به
   فهرست فیلدهای اختیاری اضافه می‌کند تا این تنظیمات از JSON به رندرر برسند.

نصب دستی هم ساده است: چهار فایل بالا را سر جای خودشان کپی کن و همان یک خط مربوط به
`models.py` را خودت اضافه کن (در انتهای همین فایل توضیح داده شده).

## ۳) از کجا استفاده کنم؟

در داشبورد، تب ۳ → پنل **«🎆 افکت‌های لایه‌ای روی کلیپ»**:

| دکمه / کلید | کار |
|---|---|
| ⚡ **صاعقه روی کلیپ** (دکمهٔ لمسی در تب ۱) | افزودن صاعقه در همان ثانیهٔ پخش، بدون نیاز به کیبورد |
| 🌧️ **باران: روشن/خاموش** (دکمهٔ لمسی در تب ۱) | همان تیک «باران پیوسته»، با یک تپ |
| 🌧️ **یک رگبار ۸ ثانیه‌ای** (دکمهٔ لمسی در تب ۱) | همان رخداد «باران طوفانی» (کلید R) با یک تپ |
| 🌧️ **باران پیوسته روی تصویر** (تیک) | باران روی کل کلیپ، مستقل از صاعقه |
| 🌧️ **باران طوفانی (R)** | یک رخداد ۸ ثانیه‌ای با زمان دقیق روی تایم‌لاین |
| ⚡ **ثبت صاعقه روی کلیپ (L)** | یک رخداد صاعقه روی تایم‌لاین |
| ⚡ **صاعقهٔ تایم‌لاین فعال** (تیک) | روشن/خاموش کردن رخدادهای صاعقه بدون پاک کردنشان |

> **📱 موبایل / بدون کیبورد:** کلیدهای میانبر (`L` صاعقه، `R` باران طوفانی، `F/G/H/J` بقیه) فقط با کیبورد
> فیزیکی (ویندوز/لینوکس) کار می‌کنند. روی گوشی و تبلت از سه دکمهٔ لمسی **تب ۱** استفاده کن:
> «⚡ صاعقه روی کلیپ»، «🌧️ باران: روشن/خاموش» و «🌧️ یک رگبار ۸ ثانیه‌ای» — دقیقاً همان افکت‌ها را
> در همان ثانیهٔ پخش روی تایم‌لاین ثبت می‌کنند (همان تابعی که کلید میانبر صدا می‌زند).
>
> **⚡ صاعقه و 🌧️ بارندگی از ماژول `lyrax-storm.js` می‌آیند**
>
> * تیک **«🌧️ باران پیوسته روی تصویر»** عیناً همان `LyraxStorm.setRain(true/false)` است؛
>   خاموش/روشن کردنش کل بارش را (هم باران پیوسته و هم رخداد «باران طوفانی» با کلید R)
>   کنترل می‌کند و تنظیمات پنل (تراکم/سرعت/زاویه/شفافیت/طول/رنگ) هم به همان ماژول می‌رود.
> * دکمهٔ **«⚡ ثبت صاعقه روی کلیپ»** (یا کلید **L**) رخداد صاعقه را روی تایم‌لاین می‌گذارد و
>   رسمش را همان ماژول انجام می‌دهد: شروع از گوشهٔ بالا، midpoint displacement بازگشتی،
>   شاخه‌های تصادفیِ قطعی، سه‌بار کشیدن هاله/بدنه/هسته و فلاش کوتاه پشت صحنه.
> * ⚠️ **رعدوبرقِ هماهنگ با ضرب آهنگ** (پنل بالا با دکمه‌های «رعد قوی و کلفت» و
>   «رعد شاخه‌دار») کاملاً جدا و **دست‌نخورده** است؛ این ماژول به آن کاری ندارد.
>   صاعقه ≠ رعد: صاعقه یک رخداد زمان‌بندی‌شده روی تایم‌لاین است، رعد افکت هماهنگ با بیت. 

زیر همان پنل، بخش **«تنظیمات باران و صاعقه»**:
تراکم، سرعت، زاویهٔ قطره‌ها، شفافیت، طول قطره، رنگ باران، مبدأ صاعقه (متناوب/چپ/راست/وسط/تصادفیِ قطعی)،
تعداد شاخه‌ها و ضخامت صاعقه. رنگ و شدت نور صاعقه از همان پنل قدیمی «رعدوبرق هماهنگ با ضرب» می‌آید
تا دو جا تنظیم نشود.

هر دو افکت **مستقل**اند: می‌توانی فقط باران، فقط صاعقه، یا هر دو را هم‌زمان داشته باشی.

```json
    "opacity": 30, "length": 1.0, "color": "#AEC2E0"
  },
  "weather_lightning": {
    "start": "alternate", "branches": 3, "thickness": 1.0,
    "color": "#FFF700", "intensity": 80
  },
  "layer_fx": [
    { "t": 2.0, "type": "rain_storm", "duration": 8.0 },
    { "t": 5.5, "type": "lightning_storm", "duration": 2.4 }
  ]
}
```

## ۵) چرا پیش‌نمایش و رندر یکی می‌شوند؟

* هر دو موتور از یک PRNG قطعی (`mulberry32`) با همان seed و **همان ترتیب فراخوانی** استفاده می‌کنند.
* حرکت باران تابعی خالص از زمان است؛ دورهٔ پایه ۸ ثانیه و هر قطره در هر دوره تعداد صحیحی
  دور کامل می‌زند، پس پرش و اختلاف فاز ندارد.
* هندسهٔ صاعقه در پایتون عیناً همان `buildBolt` جاوااسکریپت است (بازگشتی، انشعاب با احتمال ۰٫۴،
  طول شاخه ۰٫۴ قطعه) و همان سه‌بار کشیدن هاله/بدنه/هستهٔ سفید و همان منحنی پالس فلاش.
* در ASS، باران با `\move` عمودی روی یک خط موربِ ثابت رسم می‌شود (لایهٔ ۰ = پایین‌ترین لایه)
  و صاعقه/فلاش در لایهٔ ۳ روی همه‌چیز.

## ۶) اگر خواستی دستی `models.py` را پچ کنی

در `backend/models.py`، داخل `Project.from_dict` این تاپل را پیدا کن:

```python
for optional_key in (
    "subtitle_defaults", "audio_eq", "watermark", "lightning",
    "manual_lightning_timestamps",
):
```

و سه کلید را اضافه کن:

```python
    "subtitle_defaults", "audio_eq", "watermark", "lightning",
    "manual_lightning_timestamps", "rain_overlay", "weather_lightning", "layer_fx",
```

همین. بدون این سه کلید، پیش‌نمایش مرورگر کار می‌کند اما رندر سروری این افکت‌ها را نمی‌بیند.

## ۷) اجرا در ترموکس (اندروید)

داشبورد **تک‌فایلی** است و همهٔ ماژول‌ها داخل خودش تزریق شده‌اند؛ پس نه npm لازم است نه build.
اگر می‌خواهی از همان مخزن اجرا کنی:

```bash
# ۱) پیش‌نیازها (یک‌بار)
pkg update -y && pkg install -y git python

# ۲) گرفتن پروژه
cd ~ && git clone -b arena/6a58b759-melyrax https://github.com/Hadi111-php/meLyrax.git
cd meLyrax

# ۳) سرو کردن داشبورد روی پورت ۸۰۰۰
python -m http.server 8000
```

بعد در مرورگر گوشی برو به: `http://127.0.0.1:8000/studio/lyrax-studio-pro-v4-weather.html`

> راه ساده‌تر: می‌توانی همان فایل `studio/lyrax-studio-pro-v4-weather.html` را مستقیم با مرورگر
> گوشی (file://) باز کنی؛ هیچ فایل خارجی لازم ندارد.
